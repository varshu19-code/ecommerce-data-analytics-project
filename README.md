# E-Commerce Data Analytics Project

## Overview
End-to-end data analytics project analyzing 51,000+ e-commerce orders
using Excel, SQL, and Power BI.

## Tools Used
- Microsoft Excel — Data Cleaning & Analysis
- SQL — Data Querying & Insights
- Power BI — Interactive Dashboard

## Project Structure

### Level 1 — Data Cleaning & Excel Analysis
- Cleaned 51,000+ records
- Removed duplicates, handled nulls, fixed date formats
- Built Pivot Tables and Charts

### Level 2 — SQL Analysis
- Wrote 10+ SQL queries
- Analyzed sales, profit, customers, regions and shipping

### Level 3 — Power BI Dashboard
- 3-page interactive dashboard
- KPI cards, slicers, bar charts, line charts, donut charts

## Key Insights
- Total Sales: $13M | Total Profit: $1.47M
- Central region leads with $2.8M in sales
- Technology is the most profitable category at 45%
- Sales peak every November and December
